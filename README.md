# 윷빵 (yutbbang)

전통 윷놀이를 모바일과 데스크톱에서 즐길 수 있게 만든 Flutter 게임입니다.
게임판은 Flame으로 렌더링하고, 상태는 Riverpod 3로 관리합니다.

- 2~4팀 대전. 팀마다 사람 또는 CPU(난이도 1~10)를 맡길 수 있고, 모두 CPU로 두면 관전 모드가 됩니다.
- 빽도 날기, 자동 임신, 전낙, 군밤 모드 등 하우스 룰을 켜고 끌 수 있습니다.
- 아이템 모드에서는 선물 상자 칸과 아이템 9종이 등장합니다.
- 컨트롤 모드에서는 게이지 타이밍으로 낙을 피합니다.
- Android, iOS, macOS, Windows, Linux, Web을 지원합니다.

## 게임 방법

자세한 규칙은 앱의 **설정 → 윷놀이 가이드**에서 볼 수 있습니다. 가이드 내용은 `lib/presentation/guide/guide_content.dart`에 있습니다.

### 한 턴의 진행

1. 윷을 던집니다. 윷·모가 나오거나 상대 말을 잡으면 한 번 더 던집니다.
2. 나온 결과는 **나온 순서대로** 하나씩 씁니다. 결과마다 움직일 말을 고릅니다.
3. 모든 말이 같은 칸에 있으면 말이 자동으로 선택됩니다.
4. 팀의 모든 말이 한 바퀴 돌아 골인하면 승리합니다.

### 윷 결과

| 결과 | 윷가락 | 이동 | 확률* |
|---|---|---|---|
| 도 | 배 1개 | 1칸 | 3/16 |
| 빽도 | 표시 막대만 배 | 뒤로 1칸 | 1/16 |
| 개 | 배 2개 | 2칸 | 6/16 |
| 걸 | 배 3개 | 3칸 | 4/16 |
| 윷 | 배 4개 | 4칸 + 한 번 더 | 1/16 |
| 모 | 등 4개 | 5칸 + 한 번 더 | 1/16 |

\* 낙이 아닐 때 기준입니다. 낙 확률은 쉬움 10%, 보통 15%, 어려움 25% 중에서 고릅니다. 빽도를 끄면 빽도 자리가 도가 됩니다.

### 판과 지름길

- 말은 오른쪽 아래 출발점에서 시작해 시계 반대 방향으로 돕니다.
- 첫째·둘째 꼭짓점에 정확히 멈추면, 다음 이동에서 대각선 지름길을 탈지 고를 수 있습니다.
- 중앙을 지나칠 때는 들어온 방향으로 직진합니다. 중앙에 멈췄다가 출발하면 항상 출발점 방향으로 갑니다.
- 같은 칸의 우리 말은 업혀서 함께 움직입니다. 상대 말이 있는 칸에 멈추면 그 말들을 잡습니다.
- 출발점 칸을 밟거나 지나치면 골인입니다. 단, 출발점 칸에 상대 말이 있으면 멈춰서 잡습니다.

### 낙과 빽도

- 낙이 나오면 그 던지기는 무효입니다. 앞서 나온 윷·모 결과가 없으면 턴이 끝납니다.
- 빽도는 판 위의 말을 왔던 길로 한 칸 되돌립니다. 판 위에 말이 없으면 버려집니다.

### 하우스 룰

| 규칙 | 설명 |
|---|---|
| 빽도 날기 | 판 위에 내 말이 없을 때 빽도가 나오면 대기 말 하나가 바로 골인 |
| 자동 임신 | 중앙에 도착하면 대기 말 하나가 자동으로 합류해 업힘 |
| 전낙 | 윷·모 뒤에 낙이 나오면 이번 턴 결과를 모두 버리고 턴 종료 |
| 군밤 모드 | 꼭짓점에서 묻지 않고 항상 지름길로 이동 |

### 컨트롤 모드

버튼을 누르고 있으면 게이지가 왕복하고, 손을 떼는 순간 윷을 던집니다. 빨간 낙 구간에서 떼면 낙입니다. 낙 확률을 높이면 낙 구간이 1개에서 3개, 4개로 늘고 게이지도 빨라집니다.

### 아이템 모드 🎁

판의 선물 상자 칸(8곳)에 멈추면 무작위 아이템을 얻습니다. 팀당 최대 2개까지 가질 수 있고, 가방이 꽉 차면 교체할지 포기할지 고릅니다.

| 종류 | 아이템 | 효과 |
|---|---|---|
| 자동 | 🛡️ 낙 방지권 | 낙이 나오면 자동으로 '도'로 바꿈 |
| 자동 | 🔄 다시 던지기 | 던진 직후 다시 던질지 물어봄 |
| 자동 | ↩️ 뒷걸음질 | 판 위 말을 도·개·걸로 움직일 때 뒤로 갈지 물어봄 |
| 가방 | 🌟 황금 윷 | 다음 던지기가 반드시 윷 또는 모 |
| 가방 | ❄️ 얼음탄 | 다음 차례 팀의 턴을 한 번 건너뜀 |
| 가방 | 🏠 강제 귀가권 | 판 위 상대 말 하나를 출발점으로 돌려보냄 |
| 가방 | ↔️ 위치 교환 | 내 말과 상대 말의 자리를 바꿈 |
| 가방 | 🧲 자석 | 내 말 앞 3칸 안의 상대 말을 모두 잡음 |
| 가방 | 🌪️ 태풍 | 판 위 모든 말을 무작위 칸으로 흩어놓음 |

가방 아이템은 쓸 수 없는 상황이면 소모되지 않습니다.

## 설정

| 구분 | 항목 | 저장 |
|---|---|---|
| 글로벌 설정 (설정 화면) | CPU 난이도, 낙 확률, 빽도, 컨트롤 모드, 하우스 룰, 아이템 모드 | 기기에 저장 (`shared_preferences`) |
| 게임 시작 설정 | 팀 수, 팀 이름, 팀별 CPU/플레이어, 말 수(2~5), 그 판의 규칙 | 해당 판에만 적용 |

```
lib/
├── main.dart                         앱 엔트리 (ProviderScope, 테마)

│   └── config_repository.dart        글로벌 설정 저장·복원
├── domain/                           Flutter 의존 없는 순수 게임 로직

│       ├── board_graph.dart          윷판 29칸 그래프

│   ├── providers/

│   │   ├── game_state.dart           GameState, GameStatus
│   │   └── game_notifier/            기능별 part 파일 (setup·throw·move·turn·item·ai_item)
│   ├── screens/                      로비, 게임 시작 설정, 게임, 설정, 가이드

test/
├── domain/                           순수 로직 단위 테스트
├── data/                             설정 저장 테스트
├── presentation/                     GameNotifier 통합 테스트, 가이드 위젯 테스트
└── helpers/fixtures.dart             팀 생성·FakeRandom 헬퍼
```

### 설계 메모

- 게임 규칙은 모두 `domain/logic`의 순수 함수로 두었습니다. 그래서 상태를 받아 새 상태를 돌려주는 형태로 테스트할 수 있습니다.
- `GameNotifier`는 순서 제어(타이머, 애니메이션 대기, CPU 차례 예약)와 상태 반영만 맡습니다.
- 난수는 `gameRandomProvider`로 주입합니다. 테스트에서 시드를 고정한 `Random`이나 `FakeRandom`으로 바꿀 수 있습니다.
